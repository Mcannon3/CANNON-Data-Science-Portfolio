# Cannon-TidyData-Project
This is an overview of my [Tidy Data Project](https://github.com/Mcannon3/CANNON-Data-Science-Portfolio/blob/main/TidyData-Project/Cannon_2008_Olympic_Medalists_TidyData_Project.ipynb)

## Project Overview
This Project is a chance to showcase my ability to clean and visualize data for the purpose of analysis. In this project I selected a dataset and reshaped the data so that:
- Each variable is in its own column
- Each observation forms its own row
- Each type of observational unit forms its own table
Next I created 2 visualizations, a bar graph and a pie chart, to reflect my newly cleaned data. Finally, I created a Pivot-Table using an aggregation function on my tidy data.

## Instructions
Running my notebook requires that one has downloaded and then uploaded the dataset "Olympic Medalists 2008" into the current working directory. It also requires that pandas and matplotlib.pyplot are imported as well. Each cell block must be run in sequential order otherwise the formatting will get messed up.

## Dataset Description
I used the dataset '2008 Olympic Medalists' which can be found [here](https://edjnet.github.io/OlympicsGoNUTS/2008/)
