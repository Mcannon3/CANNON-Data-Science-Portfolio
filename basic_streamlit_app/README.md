# Basic Streamlit App - Penguin Data Explorer
This is an interactive web built app using Streamlit! Streamlit is a Python framework to help create data apps for machine learning and data science with only a few lines of code.

# About the Data
We are using the Palmer Penguins dataset, which can be easily accessed through the Seaborn library. It includes observations for three penguin species:
- Adelie
- Chinstrap
- Gentoo

Each observation includes the following features:
- Species
- Island
- Bill length (mm)
- Bill depth (mm)
- Flipper length (mm)
- Body Mass (g)
- Sex
- Year

# App Features
- View a preview of the full dataset
- Filter penguins by species and sex
- View the filtered data in a table
- Generate summary statistics

# How to run the app

1. Install streamlit
2. Clone the Repository
3. Install Requirements
4. Run the app using the command 'streamlit run main.py'
